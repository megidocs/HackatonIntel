# הערכת ידע ליבה · אבטחת מידע

קרא קודם את [הפרוטוקול המשותף](../assess-core-knowledge/protocol.md) ופעל לפיו. הקובץ הזה מגדיר רק את התוכן.

**סעיף אפיון:** [6.1 אבטחת מידע](../../../docs/specification.md#61-אבטחת-מידע-security).

## מושגי ליבה

1. מודל איומים: נכס, תוקף, איום, מנגנון הגנה.
2. אימות (מי אתה) מול הרשאה (מה מותר לך). ‏JWT ו-RBAC.
3. Replay: חותמת זמן ו-nonce.
4. GPS Spoofing ובדיקת סבירות.
5. הזרקת SQL ושאילתות פרמטריות.
6. הצפנה בתעבורה: ‏TLS, ‏HTTPS ו-WSS.
7. DoS ו-rate limiting.
8. פרטיות: מזעור נתונים, TTL למיקום אזרח.
9. Audit Log והרשאה מינימלית.

## בנק שאלות

### מושג

- **מה ההבדל בין אימות להרשאה? איפה כל אחד ב-ClearPath AI?**
  תשובה טובה: אימות בודק שהמשתמש הוא מי שהוא טוען (התחברות, ‏JWT חתום). הרשאה בודקת מה מותר לתפקיד שלו (רק Emergency Unit משויך לאירוע פתוח מבקש עדיפות).
- **מה יש ב-JWT, ומה מבטיחה החתימה שלו?**
  תשובה טובה: כותרת, תוכן (מזהה, תפקיד, תוקף) וחתימה. החתימה מבטיחה שהתוכן לא שונה. היא **אינה** מצפינה אותו, ולכן לא שמים בו סודות.
- **מה זו מתקפת Replay?**
  תשובה טובה: הקלטה של הודעה תקינה ושליחתה מחדש מאוחר יותר. החתימה תקינה, ולכן אימות לבד אינו מספיק.

### החלטה במערכת

- **למה האיום המרכזי הוא התחזות לרכב חירום?**
  תשובה טובה: מי שמתחזה מקבל גל ירוק, ויכול לשבש את התנועה בעיר ולסכן אנשים.
- **למה דיווח של אזרח לא משנה מסלול לפני אישור מוקדן?**
  תשובה טובה: דיווח כוזב יכול להסיט רכבי חירום. אדם מאשר, ו-rate limiting מגביל הצפה.
- **למה מיקום האזרח נשמר רק דקה ב-Redis ולא בבסיס הנתונים?**
  תשובה טובה: מזעור נתונים. המיקום נחוץ רק לבדיקת ה-Geofence. שמירה לאורך זמן יוצרת מאגר מעקב רגיש, שדליפה ממנו פוגעת בפרטיות.
- **למה כל פקודת עדיפות נרשמת ב-Audit Log?**
  תשובה טובה: כדי לחקור שימוש לרעה ותקלות: מי, מתי ובגלל איזה אירוע.

### חישוב או הרצה ביד

- **בדיקת סבירות GPS.** בחר שתי דגימות חדשות: מרחק ביניהן (למשל 900 מטר) וזמן (למשל 3 שניות). שאל: מה המהירות? האם השרת צריך לקבל את הדגימה, אם המהירות המקסימלית הסבירה היא X?
  תשובה טובה: מהירות = מרחק חלקי זמן. 900 מטר ב-3 שניות הם 300 מטר לשנייה, יותר מ-1,000 קמ"ש. דוחים, ובודקים גם התאמה לרשת הכבישים.
- **חלון Replay.** בחר חותמת זמן של הודעה ושעון שרת, ושאל אם ההודעה מתקבלת לפי חלון של 2 שניות. ואם היא בתוך החלון אבל כבר התקבלה?
  תשובה טובה: מחוץ לחלון נדחית. בתוך החלון, ה-nonce נבדק מול רשימת ה-nonces שהתקבלו בחלון האחרון. הודעה חוזרת נדחית.

### מה אם

- מה אם התוקף גונב JWT של נהג אמבולנס?
  תשובה טובה: יכול להתחזות עד שהתוקף פג. לכן תוקף קצר, ביטול tokens, הצפנת התעבורה, ובדיקת סבירות מיקום מול הרכב המשויך.
- מה אם התקשורת לא מוצפנת?
  תשובה טובה: האזנה חושפת את מיקומי רכבי ההצלה, וגם tokens שאפשר לגנוב.
- מה אם מישהו כותב בשדה תיאור האירוע `'; DROP TABLE Incidents; --`?
  תשובה טובה: עם שאילתה פרמטרית הטקסט נשמר כנתון ולא מורץ כקוד.
- מה אם אלפי חיבורי WebSocket נפתחים מאותו משתמש?

### איתור שגיאה

```python
query = f"SELECT * FROM Incidents WHERE description LIKE '%{user_text}%'"
cursor.execute(query)
```

תשובה טובה: הזרקת SQL. צריך שאילתה פרמטרית: `cursor.execute("... LIKE ?", (f"%{user_text}%",))`.

```python
def request_preemption(token, intersection_id):
    user = decode_jwt(token)          # signature verified
    grant_green(intersection_id)
```

תשובה טובה: יש אימות, אבל אין הרשאה. לא נבדק שהתפקיד הוא Emergency Unit, שהוא משויך לאירוע פתוח, ושההודעה טרייה. אין רישום ב-Audit Log.

## טעויות נפוצות לזיהוי

- "JWT מוצפן."
- "HTTPS מגן מפני כל המתקפות." הוא לא מונע Replay או התחזות של משתמש מאומת.
- בלבול בין אימות להרשאה.
- פרטיות כ"סיסמה חזקה" ולא כמזעור ומחיקת נתונים.
