‫רכיב בלי תגית: פועל ונבדק, אבני דרך 1–5. שיבוץ מאומת רץ כרגע במחשב ההדגמה. ה-AI מציע בלבד.‬

הארכיטקטורה כפי שהיא בקוד היום. במרכז שרת FastAPI בפייתון, שרץ בשני מקומות: באופן מקומי במחשב ההדגמה, ובאופן ציבורי בשירות Render החינמי, בתוך קונטיינר Docker ובכתובת HTTPS. השרת מחזיק את שעון הסימולציה, מחשב מסלולים ב-A* על גרף הרחובות של מנהטן, מתזמן את הגל הירוק ומתריע לאזרחים בדרך. מימין הלקוחות, וכולם רואים את אותו מצב סימולציה: הסימולטור בדפדפן, ואפליקציית Android שנבנתה ב-Flutter, בתפקיד נהג ההצלה ובתפקיד האזרח. הטלפונים מקבלים עדכוני WebSocket כל 200 מילישניות. באבן הדרך החמישית נוספו שיבוץ והרשאות: מסד PostgreSQL ב-Supabase עם שש טבלאות ואבטחה ברמת השורה, כניסה דרך Supabase Auth שמנפיק אסימון JWT, ותפקיד לכל משתמש: מוקדן, נהג הצלה או אזרח. טרנזקציה מונעת שיבוץ של אותו רכב לשני אירועים, ו-Redis במחשב ההדגמה מחזיק את המיקום האחרון ומונע שידור חוזר. השיבוץ המאומת פועל כרגע במחשב ההדגמה בלבד. בשרת הציבורי הוא כבוי, ושינוי התרחיש שם מוגן בקוד מציג. משמאל, GitHub Actions בודק כל שינוי לפני ש-Render מפרסם אותו. מודל השפה לחילוץ דיווחים ולעוזר המוקדן עדיין מתוכנן. עיקרון הבטיחות: ה-AI רק מציע, ופקודות לרמזורים ושיוך רכבים עוברים בקוד דטרמיניסטי.
