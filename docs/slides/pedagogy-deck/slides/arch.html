‫רכיב בלי תגית: פועל ונבדק, אבני דרך 1–4. ה-AI מציע בלבד, והרמזורים נשלטים בקוד דטרמיניסטי.‬

הארכיטקטורה כפי שהיא בקוד היום. במרכז שרת FastAPI בפייתון. אותו שרת רץ בשני מקומות: באופן מקומי במחשב ההדגמה, ובאופן ציבורי בשירות Render החינמי, בתוך קונטיינר Docker ובכתובת HTTPS. השרת מחזיק את שעון הסימולציה, מחשב מסלולים ב-A* על גרף הרחובות של מנהטן מ-OpenStreetMap, מתזמן את הגל הירוק ברמזורים ומתריע לאזרחים בדרך. מימין הלקוחות, וכולם רואים את אותו מצב סימולציה. הסימולטור בדפדפן מציג את מפת מנהטן ב-MapLibre וקורא את המצב ב-REST. אפליקציית Android, שנבנתה ב-Flutter, פועלת בשני תפקידים: נהג ההצלה מקבל מסלול ומיקום, והאזרח מקבל התרעה מוקראת לפנות את הנתיב. שניהם מקבלים עדכוני WebSocket כל 200 מילישניות. בפריסה הציבורית, שינוי התרחיש דורש קוד מציג. משמאל: GitHub Actions בונה את קונטיינר ה-Docker ובודק אותו תחת מגבלות המעבד והזיכרון של Render, ו-Render מפרסם גרסה חדשה רק אחרי שהבדיקות עברו. עדיין מתוכננים Redis, מסד PostgreSQL ב-Supabase, ומודל השפה לחילוץ דיווחים ולעוזר המוקדן. גם GPS אמיתי מהטלפון והתרעות ברקע נשארו מחוץ לחזרה הנוכחית. עיקרון הבטיחות: ה-AI רק מציע, ופקודות לרמזורים ושיוך רכבים עוברים בקוד דטרמיניסטי.
